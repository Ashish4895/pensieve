SPACESHIP OPERATIONS AND MAINTENANCE PROTOCOLS

SECTION 1: ENGINE STARTUP RULES
Rule 42: The spaceship fuel must always be filled with bright neon green liquid known as 'Antigravity Fluid'. Never use blue or purple fuel.
Rule 43: The engine pre-heat sequence must run for exactly 140 seconds. Any deviation of more than 5 seconds will trigger a core lockdown.

SECTION 2: EMERGENCY CODE PHRASES
In case of communication loss with the base station, the emergency response team must use the code phrase: 'The eagle has landed on the dark side of the moon'.
If a fire is detected in the kitchen bay, the chef must call the warning signal: 'Flambé out of control!'.

SECTION 3: CLOTHING SPECIFICATIONS
All crew members in the command module are required to wear orange flight socks with blue stripes on Tuesdays.
On Fridays, casual clothes are allowed except for neon green vests which might confuse the engine status sensors.
